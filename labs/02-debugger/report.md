Система: Windows 11 · отладчик: Visual Studio (MSVC)

## Остановка и переменные
Программа без отладчика напечатала: agent: total=6 area=12
Точка останова на строке 15 (выделилась struct point p = {3, 4};).
До строки 15: p.x = 7, p.y = 0, total = 32759.
После строки 15: p.x = 3, p.y = 4.
Строку 16 отладчик пропустил, потому что в ней нет исполняемого кода, просто выделяется память под массив.
name[0] = 'a' (её числовой код - 97) (код буквы), завершающий ноль в ячейке name[5] (там значение 0).
